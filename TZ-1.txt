2. Цели и задачи
2.1. Бизнес-цели
Собирать квалифицированные заявки на расчёт стоимости обслуживания недвижимости.

Минимизировать отсев на воронке за счёт понятного и быстрого UX.

Не терять заявки: доставка через 3 канала одновременно (Email, WhatsApp, Telegram).

2.2. Продуктовые задачи (MVP)
✅ Одностраничный лендинг с ключевыми блоками.

✅ 4-шаговая форма заявки с картой, иконками, валидацией и автоотправкой.

✅ SEO-оптимизация на 3 языка.

⏳ Backend для приёма заявок (Cloudflare Worker + D1 + Telegram Bot).

⏳ Публикация PDF-договоров на 3 языках.

⏳ Google Search Console verification.

⏳ Cloudflare Web Analytics token.

5.2. Модальное окно «Расчёт стоимости»
Общие правила:

Высота: max-height: 92vh.

Скролл запрещён (правило: .modal-body { overflow: hidden; min-height: 0 }).

Навигация: круглые стрелки ← → на одном уровне с прогресс-баром.

Заголовок центрирован и меняется по шагу.

На экране «Успех» — навигация скрыта.

Шаг 1: Выбор места на карте
Интерактивная карта Leaflet (CRS.Simple + imageOverlay).

Сетка 60×80 наложена через Canvas (прозрачность 90%).

Клик по ячейке зоны A/B/C → ставится одна точка (старая удаляется).

Стрелка «Далее» неактивна до клика по зоне.

Без скролла — карта занимает всю доступную высоту.

Шаг 2: Тип объекта + частота
2 ряда по 3 иконки, без текстов-подсказок.

Цветовые схемы: дом (терракота), квартира (циан), участок (олива); пустует — большая часть года (teal), сезонно (янтарь), периодически (серый).

«Далее» активна после выбора в обоих рядах.

Шаг 3: Услуги
4 таба (Жильё / Сад / Бассейн / Гараж) с цветными иконками.

Точка-индикатор на табе, если выбраны подуслуги.

Подуслуги — toggle-иконки 3-4 штуки на таб.

«Далее» активна при ≥1 выбранной подуслуге.

Шаг 4: Контакты
3 поля ввода: Email, WhatsApp, Telegram.

Зелёная точка-индикатор валидности у каждого поля.

Поле «Имя» — обязательно.

Чекбокс согласия (полный текст согласия с упоминанием ООО «ССС»).

Пользователь может заполнить от 1 до 3 каналов, «Далее» активна если хотя бы один валиден + имя + галочка.

5.3. Экран «Успех»
Автоматическая отправка через все заполненные каналы.

Кнопки Email / WhatsApp / Telegram появляются последовательно.

Каждая кнопка: анимация нажатия (0.8 с) → зелёная галочка «отправлено».

После завершения всех анимаций — таймер 65 секунд с текстом «Окно закроется через X сек».

По истечении — модалка закрывается автоматически.

5.4. Мультиязычность
Переключатель RU / EN / ES в шапке.

Все строки в объекте I18N.

Динамическое обновление <title>, description, canonical, og:*, hreflang, JSON-LD FAQ.

URL-роутинг: /ru/, /en/, /es/ через _redirects.

Дефолтный язык: en (для SEO).

Все поля с <label>.

6.4. Безопасность
Turnstile на шаге 4 (антиспам).

Rate-limit 3 заявки / 60 сек по IP (SHA-256 хеш, не raw IP).

Все поля обрезаются по длине.

_headers: CSP, X-Frame-Options, HSTS, Permissions-Policy.

/admin.html — за Cloudflare Access.

10. Деплой
10.1. Порядок
bash
# 1. Установка
npm install -g wrangler

# 2. Авторизация
wrangler login

# 3. Создание D1
wrangler d1 create domtenerife-leads
# → скопировать database_id в wrangler.toml

# 4. Применение схемы
wrangler d1 execute domtenerife-leads --remote --file=./schema.sql

# 5. Секреты
wrangler pages secret put TELEGRAM_BOT_TOKEN
wrangler pages secret put TURNSTILE_SECRET

# 6. Деплой
wrangler pages deploy .

# 7. Обновление без изменений конфига
wrangler pages deploy .
# → hard-reload в браузере (Ctrl+Shift+R)
10.2. Откат
dash.cloudflare.com → Workers & Pages → casacaretenerife → Deployments → Rollback.

12. Правила разработки (для команды)
Сначала анализ, потом код. Не переписывать файл без явного «ок» от заказчика.

Никакого овер-инжиниринга. Vanilla JS без фреймворков. Никаких React/Vue.

Никакого скролла в модалке — это архитектурное правило. Если контент не влезает, уменьшать шрифты/отступы, а не добавлять скролл.

Прогрессивное раскрытие — показывать пользователю только то, что нужно на текущем шаге.

Одна переменная за раз — если ломается, легче откатить.

Мультиязычность через i18n — все строки в словарях, никакого текста в JSX/HTML напрямую.

Проверка на реальном устройстве — эмулятор Chrome ≠ iPhone Safari.
