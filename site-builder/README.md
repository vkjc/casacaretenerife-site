# Site Builder — фазы 1–2 + капча и письма

Визуальный редактор сайтов на бесплатном Cloudflare: Workers + D1 (+ R2 по желанию). Без фреймворков и сборщиков.
Фаза 1: сетка, текст, медиа/карусель, публикация. Фаза 2: элементы управления, модальные окна, переключатель языков (LTR и RTL), заявки.
Добавлено перед фазой 3: капча Turnstile на публичных формах и письма о новых заявках.

## Запуск (с нуля) и обновление с фазы 1
```
wrangler auth create tecasacare     # при первом запуске войдите в tecasacare@gmail.com
wrangler secret put ADMIN_TOKEN --profile tecasacare
wrangler secret put ADMIN_PATH --profile tecasacare
wrangler deploy --profile tecasacare
```
`wrangler.toml` закрепляет отдельные account ID и D1. Используйте профиль `tecasacare` для всех команд Wrangler, чтобы случайно не развернуть редактор в общем препроде.
Сайт: `https://site-builder.tecasacare.workers.dev/` · Редактор: `https://site-builder.tecasacare.workers.dev/s/<ADMIN_PATH>/`
Обновление с фазы 1: просто замените файлы и сделайте `wrangler deploy --profile tecasacare`. Воркер сам добавит таблицу заявок и колонку `meta`,
а старые настройки получат разрешение на новые блоки. Уже опубликованные страницы нужно опубликовать заново (появятся формы и переводы).
Отдельная D1 указана в `wrangler.toml`; её схема доступна в `schema.sql`. R2 (загрузка файлов) — по желанию, см. `wrangler.toml`.

## Что нового в фазе 2
**Элементы управления** (блок «Элемент», вид выбирается в панели справа или в меню правого клика):
кнопка, поле ввода, текстовая область, радио-кнопки, чек-лист, выпадающий список, галочка согласия (с ссылкой), меню.
- Форматы поля: текст, email, телефон (с кодом страны), Telegram-ник, WhatsApp (номер), ссылка, число. Обязательность, мин./макс. длина, своя подсказка и своя ошибка.
- Проверка идёт в браузере и повторно на сервере ОДНИМ кодом (`validateField` в `render.js`) — обойти её запросом в API нельзя.
- Кнопка: ничего / открыть ссылку / **открыть окно** / закрыть окно / **отправить форму**. Меню: пункты-ссылки и пункты-окна.
- Отправка собирает все поля своей области (страницы или окна). Заявки: кнопка 📥 сверху (список, удаление, экспорт CSV).

**Модальные окна** — это страницы типа «окно»: кнопка `＋🗔` создаёт окно, оно редактируется в том же редакторе (сетка, текст, медиа, элементы, даже другие окна).
В настройках кнопки есть выбор окна, `＋` создаёт новое, `✎` открывает на правку, «← Назад» возвращает. Ширина окна — в панели справа, когда блок не выбран.
«Опубликовать» на странице встраивает все нужные окна (до 3 уровней вложенности, циклы безопасны). «Опубликовать» на окне обновляет страницы, которые его вызывают.

**Языки (LTR и RTL).** Блок «Языки» (список или кнопки). Все тексты хранятся по языкам; страница публикуется со всеми переводами в одном файле,
выбор языка перерисовывает тексты, подсказки, плейсхолдеры, подписи кнопок, варианты, alt-тексты, сообщения об ошибках, окна, меняет `lang` и `dir` страницы (RTL зеркалит сетку и карусель)
без перезагрузки. Выбор запоминается; страницы без блока «Языки» всегда открываются на языке по умолчанию. Переводы: «🌐 Переводы» (таблица всех строк страницы, красным — непереведённые) или переключатель языка в верхней панели.
Языки, направление и язык по умолчанию — в ⚙. Стандартные тексты ошибок есть для en, ru, ar, he (для остальных — язык по умолчанию или английский).

## Капча и письма о заявках
**Капча (Cloudflare Turnstile).** Невидимая: окно с проверкой появляется, только если Cloudflare сомневается.
1. Cloudflare → Turnstile → Add widget, получите Site key и Secret key.
2. `wrangler secret put TURNSTILE_SECRET`
3. В редакторе: ⚙ Настройки → «Капча» → вставьте Site key. Опубликуйте страницы заново.
Пока секрет задан, сервер не принимает заявки без проверенного токена (даже прямым запросом в API). Пустой Site key убирает капчу с сайта, но если секрет остался, формы перестанут принимать заявки: уберите и секрет (`wrangler secret delete TURNSTILE_SECRET`).
Для проверки есть тестовые ключи Cloudflare (всегда проходят): Site key `1x00000000000000000000AA`, Secret `1x0000000000000000000000000000000AA`.

**Письма.** Воркер не умеет SMTP, поэтому два способа (нужен адрес отправителя на вашем домене):
- *Cloudflare Email Routing*: `[[send_email]] name = "EMAIL"` в `wrangler.toml`, домен в Cloudflare, адреса получателей подтверждены в Email Routing. Бесплатно.
- *Resend*: `wrangler secret put RESEND_API_KEY`, домен подтверждён в Resend.
В обоих случаях задайте `NOTIFY_FROM` (блок `[vars]` в `wrangler.toml`). Получатели и тема письма: ⚙ Настройки → «Письма о заявках»; там же кнопка «Сохранить и отправить тестовое письмо», которая показывает причину, если не вышло.
Письмо уходит после ответа посетителю; статус (`отправлено` или причина ошибки) виден у каждой заявки в 📥. Заявка не теряется, даже если почта не сработала. Reply-To ставится на email из формы, чтобы отвечать кнопкой «Ответить».

## Библиотека медиа (левая панель)
Кнопка «Медиа» в верхней строке показывает или скрывает левую панель. Нужен R2 (см. `wrangler.toml`); без него медиа вставляются по URL.
- Пока библиотека пуста, панель скрыта; после первого файла остаётся узкая боковая ручка, которая раскрывается при наведении, не перекрывая холст. Кнопка «Медиа» закрепляет или скрывает панель.
- **Загрузка:** перетащите файлы в зону загрузки или выберите на компьютере; в блоке «Медиа» есть кнопка «Загрузить», которая сразу добавляет файлы в ленту. Видны проценты и итог сжатия.
- **Сжатие:** фото больше 2000 px или тяжелее 350 КБ перекодируются в браузере в WebP, если файл от этого уменьшается (GIF, AVIF и видео не трогаются). Видео: mp4 и webm до 50 МБ, длительность определяется автоматически.
- **Имена:** исходное имя сохраняется (поле «Оригинал»), видимое имя уникально без учёта регистра: при совпадении добавляется « (2)», « (3)». Файл можно переименовать (занятое имя не принимается); адрес файла `/media/<ключ>` при этом не меняется, поэтому страницы не ломаются.
- **Теги и подсказки:** у файла до 12 тегов и подсказка на каждом языке сайта. Подсказка и теги появляются при наведении на миниатюру и на медиа на холсте (там ещё имя файла). Посетителям показывается только текст подсказки (переключатель «Подсказки файлов» в блоке). Правка в библиотеке действует во всех блоках и после публикации страниц.
- **Поиск:** по имени, тегам и тексту подсказок; фильтр по тегам. Значок на миниатюре — на скольких страницах файл используется.
- **В ленту:** клик по файлу при выбранном блоке «Медиа», перетаскивание файла на блок или кнопка «Из библиотеки». Правый клик по файлу: правка, добавить, копировать адрес, удалить.
- **Удаление:** файл, который используется на страницах, удаляется только после подтверждения.
- **Ячейки ленты:** галочка слева выключает ячейку, не удаляя её из блока; «Показывать первые N» оставляет в ленте только N ячеек (0 — все).

## Язык интерфейса редактора
Переключатель рядом с языком редактирования (RU/EN); по умолчанию берётся язык браузера. Это язык панелей, кнопок и сообщений редактора, он не связан с языками сайта.
Язык интерфейса добавляется в `public/_editor/ui.js`: `UI.add("de", { "Сохранить": "Speichern", … }, "Deutsch", "ltr")` (русская строка из кода — ключ, `{0}` — подстановка; нет перевода — берётся английский). Для арабского и иврита укажите `"rtl"`.

## Безопасность
Перечень найденных проблем, исправлений и остаточных рисков: `SECURITY.md`. Главное: токен не короче 32 случайных символов, Cloudflare Access перед `/s/*` и `/api/admin/*`, Turnstile на формах, затем перенос CSP из режима Report-Only в боевой.

## Автотесты
`npm install && npm test` (Node 22). Тесты лежат в `tests/`: воркер (страницы, формы, медиа, каталог, безопасность) и отрисовка. Редактор в браузере пока проверялся вручную в тестовом браузере; автотесты для него добавляются в следующем шаге.

## Структура
- `src/worker.js` — публикация страниц, API редактора, приём заявок, R2
- `public/_editor/` — редактор (`editor.js`, `ui.js` — языки интерфейса); `render.js` общий для холста, публикации и сервера; прямой доступ закрыт
- `schema.sql` — таблицы D1: settings, pages, versions, published, submissions, media, media_use

## Формат документа (pages.doc)
```
{ "v":1, "modal":{"w":560}?, "root": Grid }          // modal — только у окон
Grid    { id, type:"grid", layout:{d:{col,row,cs,rs}, m:{…}}, p:{cols,colsM,rows,rowH,gapX,gapY,padX,padY,radius,bg,maxW}, children:[Block] }
Text    { id, type:"text", layout, paras:[{ id, t:{<lang>:"…"}, tip:{<lang>}, s:{size,sizeM,weight,lh,ls,align,dir,color,grad,g1,g2,gAngle,ov,ovColor,ovOp} }] }
Media   { id, type:"media", layout, items:[{id,type,src,alt:{<lang>},autoplay}], p:{ frame:{…}, belt:{…}, click:{action,url} } }
Control { id, type:"control", layout, p:{ kind, name, req, fmt, min, max, label:{<lang>}, ph, help, err, linkText, link,
          options:[{id, v, t:{<lang>}, action, url, modal}], btn:{style,action,url,newTab,modal,form,ok:{<lang>},after}, menu, ac, fg, cr, fs } }
Lang    { id, type:"lang", layout, p:{ style:"select|buttons", ac, cr, fs } }
```
`layout.d` — десктоп, `layout.m` — мобильный (колонка, строка, ширина и высота в клетках).
Новые сетки по умолчанию: 80 колонок на десктопе, 32 на мобильном, шаг строки 8 px, зазоры 2 px, отступы 0 px и автоширина. Старые документы с `gap` и `pad` продолжают использовать эти значения по обеим осям.

## Ограничения
- Публичная форма защищена проверкой полей, списком известных форм, лимитом 5 заявок за 10 минут с адреса (адрес хранится только хешем) и, если включена, капчей Turnstile.
- Отправка через Cloudflare Email проверена только на уровне формирования письма (сам вызов `EMAIL.send` возможен только в Workers); через Resend проверено на заглушке сервиса. Первое реальное письмо проверьте кнопкой тестового письма.
- «Просмотр» показывает страницу и окна, но отправка форм из просмотра не работает (она работает на опубликованном сайте).
- В HTML страницы стартовый язык — по умолчанию; переключение делает скрипт (поисковики видят язык по умолчанию).
- Библиотека работает только с R2. Файлы без подсказок и тегов — внешние ссылки (они в библиотеку не попадают).
- Блок нельзя перетащить из одной сетки в другую (пока «Дублировать» + удаление).
- Имя формы должно быть уникальным для набора полей: одно имя формы в разных окнах с разными полями — ошибка публикации.
- Свободный план: версии раз в 5 минут (последние 30), страница до 400 КБ, до 800 блоков.
